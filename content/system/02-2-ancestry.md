# Ancestry

A character's ancestry is chosen during character creation.

It states which lineage the character comes from and sets values such as the number of wounds, certain traits and the starting talents.

An ancestry entry is structured like this:

- **Health** – X-Y-Z, the number of wounds a character can take per level (lvl 1 – lvl 2 – lvl 3)
- **Traits** – the traits every character of this ancestry has
- **Talents** – the talents this ancestry starts with
- **Notes** – special information about the ancestry
- **Lore** – a short overview of the ancestry's lore
