# How to roll checks

1. A player wants to take an action, or the GM calls for a check.
2. The player describes how they carry out the action and which skill they want to roll (the two should fit together).
3. The position is discussed, which defines the target of the check.
4. The position can be negotiated.
5. The player rolls X dice based on the required skill or the threads spent.
   - Any modifiers to the number or size of the dice apply here.
6. Every die showing 5+ is a success.
   - Any modifiers that affect the number of successes apply here.
7. The number of successes is compared with the scale:
   - **Red / below target:** +conflict · −effect – strong conflict and weak effect
   - **Yellow / target reached:** conflict · effect – normal conflict and normal effect
   - **Green / above target:** −conflict · +effect – weak conflict and strong effect
8. Based on conflict and effect, the character finds themselves in a new situation.
