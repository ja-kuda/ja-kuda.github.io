# Skills

Skills are a character's general abilities. Every character in Ambition uses the same skills for pretty much every action that can happen.

Of course not all characters are equally good at all skills. Every skill has a value from 0 to 5, which shows how trained and talented a character is in that area.

The value of a skill states how many d8 are rolled in a check.

The base of every check is one d8, to which a number of d8 equal to the skill used is added.
