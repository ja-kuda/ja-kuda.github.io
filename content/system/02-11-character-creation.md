# Character creation

Creating a character should be quick and fairly simple, but offer enough depth that interesting combos are still possible after the second or third character.

These steps build a level 1 character (although there isn't really a concept of levels – it's more of a starter character):

> [!note]
> Some steps can swap places – the ambition could in theory be chosen at any point, similar to distributing talents and skills. Following this order causes the least confusion.

1. **Choose an ambition**
2. **Gain maximum resolve:** 1
3. **Choose an ancestry**
   1. Wounds based on the ancestry
   2. Possible ancestry traits
   3. Ancestry talents
4. **Distribute skills**
   1. All skills start at 1.
   2. Distribute 15 points among the skills.
   3. One skill can be reduced to 0 to gain one more point.
   4. A skill can be raised to a maximum of 5.
5. **Choose traits**
   1. Choose 3 traits that represent both positive and negative character qualities.
6. **Choose talents**
   1. Choose 5 talents.

> [!tip]
> The [character builder](characters.html#builder) follows exactly these steps.
